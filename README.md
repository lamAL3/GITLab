# GITLab
Lab that takes amounts of trip and cost per trip then calculates into a summary

## How to run
Open the program in IDE/
Enter amount of trips and the cost for each trip/
Program will calculate and print total spent and average across all trips

## Example output
---Gas Expense Summary---\
Trip 1: $5.5\
Trip 2: $5.3\
Total spent on gas: $10.8\
Average per trip: $5.4
